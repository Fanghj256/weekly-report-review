# 周报撰写规范要点

## 一、外部规范依据（检索整理）

1. 机关周报制度要求（马鞍山市统计局马统〔2011〕17号《关于实行工作周报制度和月度工作情况报告制度的通知》）：文字材料**言简意赅、用数字说话、用具体工作说话**；重点工作**标明时序进度、明确完成时限**；重要事项**阐明背景、实际情况、产生的影响和效应，并提出建议对策**。
2. 公文写作通识（《党政机关公文处理工作条例》《党政机关公文格式》精神）：**准确、简洁、规范**；专有名称用全称、简称首次出现时括注；事件要素（时间、地点、主体、事项、结果）完整。
3. 实务写作经验（笔杆子材料等）：**结论先行**，先结果后过程；内容多时先写摘要；**一个段落/条目只写一个主题**；套用统一模板，保证全篇结构一致。

## 二、周报通用写作规则

1. **条目化**：一事一条，编号层级统一（一、（一）1.），不串条。
2. **动词开头、结果导向**：用"完成、起草、办理、沟通、推动、拟于…上线"等，避免只写"进行了××工作"。
3. **结论先行**：先说结果/进展，再说过程细节。
4. **用数字说话**：机构数、笔数、金额、上线时间等尽量给具体数字与时限。
5. **要素完整**：重要事项含时间、主体、结果；下周计划含完成时限。
6. **称谓统一**：同一机构全文用同一名称；"桥社"与"中再桥社"等注明关系后统一使用。
7. **语言平实规范**：不用口语、网络语；不用"我们、咱们"；避免重复用词（如"继续修改修改完善"）。
8. **详略得当**：例行内容一句话带过；节点性内容写清进展与下一步。
9. **板块归类清晰**：内容不串板块；同主题内容合并成一条。
10. **格式统一**：标题（周报名称+起止日期）、板块名、条目编号全篇一致；日期写法（"2026.7.20—7.24"或"2026年7月20日—24日"）全文二选一。

## 三、机关文稿校对五要素（参考《浅谈机关文稿校对重点》）

1. **要素**：标题、正文、附件、日期、落款逐项核对；日期以签发时间为准，用阿拉伯数字规范标注。
2. **事实**：时间、地点、人物交叉验证；政策内容与最新文件逐字核对；数据以官方发布为准并确认有效期。
3. **引文**：政治类表述不可简化生造；引用公文先引标题、后引发文字号；引用法律法规写清名称、条款。
4. **字词**：检查错字、重复、多字少字；检查语病（缺主语、搭配不当、语序不当、自相矛盾）。
5. **版式**：字体字号行距、页码连续性、附件完整性与格式。

原则：「逢文必校、每字必核，校写分离、先排后校，急文稳校、发前再校」。

## 四、汇报材料结构（参考《把好汇报材料"问题关"》）

- 汇报材料一般含：基本情况、工作亮点、存在问题、下阶段工作安排（周报对应「本周工作内容／提请支持事项／下周工作打算」）。
- 「存在问题/提请支持」部分四关：不夸大（"依然严重"→"依然存在"）、不弱化（问题要有分量）、不回避（问题与请求分开写）、不转移（不点名甩锅其他单位，写"前期与相关单位未达成一致意见"）。

## 五、会议与交流材料体例（参考《会议材料常见错情例析》）

- 多份材料合并时，标题、结构、篇幅须统一，避免体例混乱。
- 专业术语首次出现时加括号注释，或当页下方加注。
- 人名易错字（侯/候、健/键、邢/刑）须与原始名单反复核对。
- 材料排列顺序与议程一致，统一编目。

## 六、保密提示

- 周报含内部敏感信息（机构名单、未发布政策、数据），审校结果仅本机使用，不外传。
- 涉密文稿不得使用互联网工具或人工智能工具校对，发现涉密内容立即停止并提示用户。

## 八、名词与格式规则（同事整理）

- 政策名加引号："外来外用""分出人—经纪人"
- 文件名加书名号：《业务规则》
- 机构简称全文统一

## 九、冗余与口语删除（同事整理）

- 不用"推进落实""汇总整理""讨论研究"等近义词连用（保留一个即可）
- 不用"做好沟通""做好服务"等口语表述

## 十、汇总与跨期要求（2026-08-11 扩充）

1. 汇总稿只保留最新进展，删除历史重复表述；同一事项两种称谓合并为一条。
2. 上期"拟于/计划…"的本期必须交代结果（已上线/已完成/延期原因与新时限）。
3. 会议/接待类条目统一归入板块5"综合工作"的"会议方面/调研接待"，不留在部门来源板块。
4. 领导周报与条线内容重合：以详细清晰版为准，合并为一条，不重复。
5. 新功能、新机构、新政策节点首次出现时写全要素（时间、主体、事项、结果）。
6. 缺失条线标注待核实，不编造；节点进展提示大事记素材。

## 日历核对（2026-09-08 起，制作周报固定步骤）

- 目的：核对当周（周报覆盖期）的会议/接待有无遗漏，与提交素材互补。
- 工具：lark-cli（user 身份付浩杰，已授权 calendar:calendar:read，一次授权长期有效）：
  `lark-cli calendar +search-event --calendar-id "feishu.cn_1Vv36IxIGLEPlZKka369Ad@group.calendar.feishu.cn" --start YYYY-MM-DD --end YYYY-MM-DD --as user`
- 日历为「SIRE的工作日历」（user 身份 role=owner）；user 身份可见性与 SIRE 自建应用不同（后者曾返回 0 条）。
- 命中待补：日历有而周报没有的会议/接待 → 补入板块5「综合工作」，并按下述两个固定子项分列。
- **归置口径（2026-09-28 用户明确）**：综合工作固定分「**会议工作**」（内部重要会议：总办会/党委会/专委会/督导会/协调会/安全生产保密委员会等）与「**调研接待**」（外部调研来访、机构来访、参观接待、联合党建来访等）两部分，两者缺一不可；其他条线汇总中夹带的会议/接待一律移入此处。

## docx 生成后自检（2026-09-30 加粗 bug 根治）

**背景**：空白/占位单元格（如"（待补充）"）没有正文段模板，填充时正文会误借**加粗的节标题模板**，导致整块正文加粗——已两次踩坑（8.24 期监管/平台、9.21 期研测）。

**生成后必须程序化检查（逐板块）**：
1. 正文段（数字开头）`run.font.bold != True`；节标题（一、二、…) `bold == True`；
2. 正文段 `rFonts@eastAsia == 仿宋_GB2312`；
3. 出现加粗的正文段 → 逐个 `run.font.bold = False` 修复后重存。

**生成逻辑要求**：fill 单元格时，正文模板必须从**有正文段的单元格**借取（或从最近一份定稿借），**禁止**在找不到正文模板时回落到加粗的标题模板（宁可报错中止）。
