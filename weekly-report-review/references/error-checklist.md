# 周报常见错误检查清单

> 每条格式：错误类型 | 判断要点 | 修改示范。示例来自2026年1—7月周报实际文本。

## A. 事实与日期类

1. **日期错误**：标题/落款年份与文件名或实际周次不符。实例：文件名《登记交易中心工作周报（2026.1.5—1.9）》，正文标题却写"（2025.1.5—1.9）"→ 改为"（2026.1.5—1.9）"。
2. **周次跨期**：标题标"6.29—7.3"、正文写"7.5"等 → 统一按实际覆盖日期。

## B. 文字与用词类

3. **重复用词**：实例"继续修改修改完善…"→"继续修改完善…"。
4. **口语化/非规范表达**："××这块""把××搞定了"→"××方面""已完成××"。
5. **称谓不统一**：同一机构前后混用（如"华泰保险经纪"与"华泰经纪"）→ 统一全称，首次出现括注简称。
   - **IT 相关表述强制统一（用户 2026-08-24 明确）**："协调IT""与IT沟通""总部信息技术部""信息科技部"等一律统一为"总部信息科技部"，全文不出现裸"IT"或"信息技术部"；外文缩写（ITSM 等）首次出现括注全称。
6. **术语使用不规范**：以 `D:\Files\公司知识库\术语表.md` 为准；"销单""核销"等同类词全文统一。
7. **缺主语或主语混乱**：看不出是哪个条线/机构做的 → 补明主体。
8. **阶段表述不清**："准备/正在"与"已完成/拟于"混用导致进展不明 → 明确所处阶段。

## C. 结构与归类类

9. **流水账**：按周一至周五逐天罗列 → 按主题合并同类项、一事一条。
10. **板块归类错误**：如平台功能事项误入市场板块 → 按内容主题归入板块3。
11. **编号断层/层级混乱**："一、"后直接跳"1."或二级标题缺编号 → 统一"一、（一）1."层级。
12. **串主题**：一条内包含两件不相关事项 → 拆分。
13. **缺「提请支持事项」**：有需要协调支持的内容却未列入 → 单列。
14. **双周报节内结构不统一**：有的小组写"一、工作进展/二、下一步计划"，有的写"一、系统功能方面/二、制度配套方面/三、下一步工作计划" → 建议统一为两段式。

## D. 内容详略类

15. **详略失衡**：日常答疑写一大段、重要上线一句带过 → 调整详略。
16. **缺数据/时限**：重点项目无具体进度或完成时限 → 补充"拟于×月×日上线/完成"。

## E. 规范与表述类（参考《公文校核错情例析》系列）

17. **政治/专有表述生造或套用**：自创"××共同体"、随意套用"两个结合"等 → 与中央文件和权威表述核对，不一致则删除。
18. **用词与机构职能不匹配**：议事协调机构"审定/决定"→"研究/审议"；"决策"与"决定"按主体职能使用。
19. **层级/范围表述错位**："县、村"→"县、镇（乡）、村"；"与其他地市交流"→同层级"与其他县区交流"。
20. **固定语序打乱**："依规依纪依法"、"党委（党组）"等不可随意调换顺序。
21. **政策引用扩大适用范围或与上位文件不一致**：引用的数据、政策口径须与最新文件核对。
22. **擅自新增限制条件或硬性目标**：如学历加"全日制"、设定增幅硬指标 → 按中央"不得设限制性条件/不提硬性目标"要求修改。
23. **时效性用词滞后**：如"政纪处分"→"政务处分"（监察体制改革后规范用法）。

## F. 会议/汇报材料类（参考《会议材料常见错情例析》《把好汇报材料"问题关"》）

24. **材料与议程/事实不符**：议程变更后主持词、名单未同步 → 临会前复核。
25. **人名书写错误**：侯/候、健/键、邢/刑等易混字 → 与原始名单反复核对。
26. **术语首次出现未注释** → 括号加注或页下注释。
27. **体例不统一**：多份材料标题、结构、篇幅各异 → 提出统一要求。
28. **问题/请求部分失真**：夸大（"依然严重"→"依然存在"）、回避（问题与请求混写）、甩锅（点名其他单位）→ 实事求是、分开表述。
29. **引用不规范**：引用公文未引文号、引用领导人讲话与原文不一致 → 先标题后字号、逐字核对。

## G. 整合类（2026-08-06 审校 7.27-7.31 周报新增）

30. **重复条目/同一事项分散表述**：同一事项在不同子项重复出现（如同一反馈材料出现 2 次、同一报送事项两种称谓各写一条）→ 合并为一条，写明最新进展，称谓全文统一。
31. **外文机构缩写直接使用未括注全称**：Aon Re、Moody、RAA 等直接出现 → 首次出现括注中文全称（如"美国再保险协会（RAA）"），拿不准的全称标「待核实」。

## H. 公司规范类（同事整理的周报修改注意事项，2026-08-07）

32. **称谓与规范表不一致**：如"上海金融管理局"、母公司部门未加"总部"、机构简称混用 → 按 `writing-standards.md` 第七节规范称谓表统一。
33. **动词选用不当**：校核/核查/核对、审核/审批/审定、汇总/梳理/统筹/协同混用 → 先查 `word-usage.md` 对应辨析。
34. **截至/截止误用**："截止2026年6月底"→"截至2026年6月底"；"截止"不能直接带时间宾语。
35. **制定/制订时态误用**："已制订完成"→"已制定完成"；"制订"只用于进行中。
36. **近义词连用冗余**："推进落实""汇总整理""讨论研究"→ 保留一个。
37. **口语表述**："做好沟通""做好服务"→ 规范表述。
38. **格式规则**：政策名未加引号、文件名未加书名号 → 按 `writing-standards.md` 第八节。

## I. 汇总整合类（2026-08-11 扩充）

39. **条线缺失未标注**：某条线未提交/留空 → 在底稿标注「待核实」，不编造内容。
40. **同一事项重复并入**：多来源同一事项写成两条（如"外来外用"在监管板块和重点项目各一条）→ 合并为最新进展一条，写明状态。
41. **会议/接待未归综合**：各部门周报的会议/接待仍留在来源板块 → 统一归入板块5"综合工作"的"会议方面/调研接待"。
42. **领导周报与条线重复**：负责人流水账与条线内容重合未合并 → 以详细清晰版为准合并，不重复。
43. **混入他组/他板块**：内容主题明显属于另一板块却归错 → 按主题归回对应板块。
44. **关键时点丢失**：汇总时删掉日期、会议、上线时间 → 保留关键时点。
45. **跨期照抄**：上期"拟于X月X日上线"本期仍原样写 → 更新为"已于X月X日上线"或新排期。

## 使用说明

- 逐条对照，命中即标出原文位置与修改建议；未命中不强行套用。
- 拿不准的（机构全称、数据、日期）标「待核实」，提示查周报原文、问带教或查台账。

46. **综合工作缺「会议工作」或「调研接待」子项**：内部管理·综合工作应固定分列这两部分；每期初稿前必须先用 lark-cli 核对当周「SIRE的工作日历」查漏补缺（命令见 SKILL.md 工作流程第 3 步），日历中有而素材无的会议/接待一律补入并归置到位。
