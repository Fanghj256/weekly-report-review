# 易混词辨析（周报用词检查参考）

> 来源：《秘书工作》「咬文嚼字」栏目（杜永道、王楠、米轩、潘波等，2025年各期），原文见 `D:\Files\公司知识库\10-公文写作学习资料\`。
> 用法：审校周报遇到以下词对时先查本表；拿不准的标「待核实」。

## 词对辨析

### 决不 / 绝不
- **决不**：主观态度，表「坚决不」。"决不半途而废""不获全胜，决不收兵"。
- **绝不**：客观现状，表「完全不」「任何情况下都不」。"绝不收取任何费用"。

### 庆祝 / 纪念
- **庆祝**：庆贺、欢庆，用于正在发生或延续的事项。"庆祝国庆"。
- **纪念**：怀念、庄重哀思，用于回顾已完成事项。"纪念××周年"。

### 措施 / 举措
- **措施**：解决某方面问题的具体办法、手段，常带定语（安全措施、防护措施）。
- **举措**：实施重大战略目标而采取的行动方案，偏宏观制度层面，常配「重要、重大」。

### 比如 / 例如
- **比如**：略口语，可加「说」；可做阐释说明、可与「又/再」连用、有连词用法。
- **例如**：正式书面；列举多项例证时多用，后常带并列分项。

### 汇报 / 报告
- **汇报**：基于管理/监督关系，对象是上级或主管单位，侧重口头或口头附书面，强调汇集整理。
- **报告**：公文文种之一，更正式严谨，侧重书面，可无特定对象（如检测报告）。

### 涵义 / 含义 / 含意
- 「涵义」是「含义」的异形词，规范写法用**含义**。
- **含义**：偏客观，指词语的基本义、字面义。
- **含意**：偏主观，指语句深意、言外之意。

### 率先 / 首先
- **率先**：带头做某事，带主动、示范、赞扬色彩。
- **首先**：最先，或按顺序/逻辑陈述，中性；可作序次标记（首先……其次……）。

### 继承 / 传承
- **继承**：对既有成果的接受与持守，偏静态。
- **传承**：代际或时空维度的动态传递，偏动态。

### 表率 / 示范
- **表率**：名词，用于人，思想精神、道德品行层面（成为表率、做表率）。
- **示范**：动词，可用于单位、机构，专业技术、行业规范层面（示范项目、示范工程）。

### 计划 / 规划
- **计划**：对具体行为的设计安排，可长可短，可带动词性宾语（计划开通、计划明天出发）。
- **规划**：宏观长远的设计布局，带名词性宾语（规划线路、规划发展方向）。

### 连接 / 联结
- **连接**：相互衔接，线性（这条路连接两地）；不能写「连结」。
- **联结**：结合成整体，平等联合（命运联结在一起）；不能写「联接」。

### 事件 / 事故
- **事件**：范围宽，可有计划、可突发、可未发生。
- **事故**：已发生并造成一定损害的意外事件。

### 校核 / 核查 / 核对
- **校核**：强调对数据、计算结果的复核验算，偏技术性。
- **核查**：强调对已有信息或问题的核实查对，偏监督性。
- **核对**：强调两方比对，确认一致性。

### 审核 / 审批 / 审定
- **审核**：审查核实，不一定有决定权。
- **审批**：必须有批准权（OA 流程用"审批"）。
- **审定**：审查后作出决定，比"审批"更正式。

### 汇总 / 梳理 / 统筹 / 协同
- **汇总**：把分散的集中起来。
- **梳理**：有条理地整理，常用于流程、逻辑。
- **统筹**：统一筹划，强调全局性。
- **协同**：协调一致地共同行动。

### 截至 / 截止
- **截至**：介词，事情仍在继续（"截至2026年6月底""截至目前"）；不写"截止2026年6月底"。
- **截止**：动词，不能直接带时间宾语（"报名已于昨日截止""截止日期为7月10日"）。

### 制定 / 制订
- **制定**：已完成（"制定方案"）。
- **制订**：进行中（"正在制订中"）；"已制订完成"为误用。

## 固定表述（不可随意改动）

- 「依规依纪依法」顺序固定，不可调换为「依纪依规依法」。
- 「两个维护」「四个意识」等政治表述须与中央文件一致，不可简化、生造。
- 「村'两委'」等特定简称须加引号；「党委（党组）」与「党组（党委）」按指代对象区分。
- 涉及机构职能的动词（审定/审议/研究/审批/请示）须与机构层级和职能匹配：议事协调机构无「决策/审定」职能，宜用「研究/审议」。
