# 周报分类体系（登记交易中心）

> 依据：2026年1—7月 28 份《登记交易中心工作周报》+ 4 份《平台建设专项工作领导小组双周报》整理。

## 一、工作周报固定结构（五大板块）

整表表头固定为：工作板块 | 本周工作内容 | 提请支持事项 | 下周工作打算。

### 1. 监管及政府事项

实际子项：一、"外来外用"政策；二、差异化监管（偿付能力、K4）；监管对接与政府事项。

- 归类规则：凡涉及监管机构（金融监管总局、上海金融监管局、市委金融办等）、政策文件、发文流程、监管调研材料 → 此类。

### 2. 市场相关事项

实际子项：一、机构服务；二、日常接待；三、重点项目（外来外用、履约管理、商飞、聚合体、数据报告、再保会议等）；四、其他事项。

- 归类规则：凡涉及市场机构（直保/再保、经纪、银行、评级机构等）的服务、接待、合作、重点项目推进 → 此类。

> **2026-08-11 调整（用户确认）**：各部门周报中的会议/接待类条目统一归入板块5"综合工作"的"会议方面/调研接待"，不再留在板块2"日常接待"；历史周报中的"日常接待"为旧版写法，整合时按新规归入综合。

### 3. 平台相关事项

实际子项：一、平台运营；二、数据服务与治理；三、平台功能优化；四、中国再保险登记系统。

- 归类规则：凡涉及业务平台、系统功能、数据中台、登记系统（引荐/激活/更名/机构编码）→ 此类。

### 4. 研究监测相关事项

实际子项：一、政策研究；二、规则完善小组；三、其他事项。

- 归类规则：凡涉及课题、调研、规则/协议/操作指引等制度文本起草修订、研究类材料 → 此类。

### 5. 内部管理相关事项

实际子项：一、党建工作；二、人力工作；三、综合工作；四、宣传工作；部分周另设「营收情况」。

- 归类规则：凡涉及党建、人事、行政综合、宣传、财务营收 → 此类。

## 二、双周报结构（平台建设专项工作领导小组）

按功能小组分节，不用五大板块：

1. 规则优化小组
2. ART配套功能建设小组
3. 履约管理机制功能小组
4. "外来外用"政策配套功能建设小组
5. "分出人—经纪人"标准化交易流程建设小组
6. 清结算功能标准化接口小组

各节建议统一为「一、工作进展 / 二、下一步计划」两段式。

## 三、五条线与板块的对应（整合时用）

五个条线（未来部门）与板块的常见对应：

| 条线 | 主要板块 |
|---|---|
| 综合管理条线 | 板块5（内部管理）为主 |
| 平台运营条线 | 板块3（平台相关）为主 |
| 国际市场条线 | 板块2/4（涉外机构、跨境业务、政策研究） |
| 政策研究条线 | 板块4（研究监测）为主 |
| 国内市场条线 | 板块1/2（监管对接、境内机构）为主 |

注意：**条线 ≠ 板块**。一条线的工作常跨多个板块，归类一律以"本条内容在做什么"为准，不按来源条线归。

## 四、高频工作主线（归类优先级）

外来外用、履约管理、商飞、跨境分入聚合体、参与人服务协议、分出人—经纪人流程、中国再保险登记系统、数据报告、ART、2026上海国际再保险会议——这些主线在多板块反复出现。

- 归类原则：按"本条内容所处环节"判断（如银行对接技术实现 → 平台；商请函发文 → 监管；机构签署协议 → 市场）。
- 拿不准时归入对应板块的「重点项目/其他事项」并标注「待确认」。

## 五、汇总规则（各条线周报 → 公司周报）

1. 五条线周报 + 领导周报 → 按五大板块合并；来源条线 ≠ 归类板块，以内容主题为准。
2. 同一事项多来源：只保留一条最新进展，写明最新状态，称谓全文统一。
3. 会议/接待类条目统一归入板块5"综合工作"的"会议方面/调研接待"（2026-08-11 用户确认）。
4. 领导周报（如负责人流水账）与条线内容重合时，以更详细、更清晰的那份为准合并，不重复成两条。
5. 保留关键时点（日期、会议、上线时间）；删除与本期无关的历史细节。
6. 跨期检查：上期"拟于X月X日…"本期必须更新为"已于X月X日…"或新计划，避免照抄。
7. 缺失条线（未提交/留空）在底稿中标注待核实，不编造内容。
8. 节点性进展（政策获批、功能上线、重大调研）可作大事记素材，按 `chronicle-material-research` 技能三问标准判断。

## 组织架构更新（2026-09 起）

- 条线部门名变化：市场条线 → **国际业务部**（飞书汇报规则名"国际业务部周报"）；平台运营条线 → **运营部**（规则名"运营部周报"）；研究监测条线下文出现"国际市场部"提法。
- 周报板块映射不变（内容主题归类）；正文称谓按最新部门名或沿用条线名，以定稿口径为准。

## 内部管理·综合工作的固定子项（2026-09-28 用户明确）

综合工作下**固定分「会议工作」「调研接待」两部分**（其余为重点工作/文字材料等）：

1. **会议工作**：内部重要会议（总办会、党委会、专委会、督导会、协调会、安全生产/保密委员会等），来源="飞书日程核对 + 各条线提交"。
2. **调研接待**：外部调研来访、机构来访、参观接待、联合党建来访等，来源同上。
3. 每期初稿前必须用 lark-cli 核对当周「SIRE的工作日历」查漏补缺（命令见 SKILL.md 工作流程第 3 步）；日历中有而素材没有的会议/接待必须补入并分别归置到上述两部分。
4. 其他条线（国际业务部/运营部/研究等汇总）中夹带的接待、会议，一律移入本板块对应部分，不在业务板块重复。
